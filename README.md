# desmaptic-website

The site [desmaptic.com](https://desmaptic.com), served by GitHub Pages from the `release` branch, and the
releases of Desmaptic Agent: the DMG and the agent's update feed are under
[Releases](https://github.com/desmaptic/desmaptic-website/releases).

The site's sources are kept private. Each publish of the site arrives here as one commit.
